# Vidéos à enregistrer

Les vidéos doivent être enregistrées depuis une exécution réelle du projet. Il ne faut pas créer une vidéo fictive ou utiliser une capture statique à la place d'une preuve de fonctionnement.

## Vidéos attendues

- `video_architecture.mp4` : démarrage de l'infrastructure, accès aux tables et logs.
- `video_pipeline.mp4` : exécution complète, contrôles qualité, quarantaine et résultat nettoyé.
- `video_application.mp4` : modèle, métriques, prévisions, dashboard et recommandation de stock.

## Contrôle avant dépôt

- image lisible ;
- son audible ;
- terminal et commandes visibles ;
- aucune donnée personnelle ou secret ;
- chaque vidéo est lisible sur un autre ordinateur ;
- la séquence correspond réellement au code fourni ;
- les commandes peuvent être rejouées à partir du README.
